# Logos

Every SVG here is flat and carries its own fills, so it can be used with `<img>`.

- `lynxdb-mark-faceted-on-light.svg` — Primary mark for light grounds (`bg-app`, `bg-surface`). Five flat moss tones, 400 to 950.
- `lynxdb-mark-faceted-on-dark.svg` — Primary mark for dark grounds. Tones 200 to 950.
- `lynxdb-mark-ink-moss.svg` — Single ink, `moss-800`. Small sizes on light grounds.
- `lynxdb-mark-ink-lime.svg` — Single ink, `moss-300`. Small sizes on dark grounds.
- `lynxdb-mark-ink-black.svg` — Single ink, `stone-950`. One-colour print.
- `lynxdb-mark-ink-white.svg` — Single ink, `stone-50`. On `accent` fills and photographs.
- `lynxdb-appicon-dark.svg` — App icon and favicon source: lime ink on a `stone-950` tile.
- `lynxdb-appicon-moss.svg` — App icon alternative: white ink on a `moss-700` tile.
- `lynxdb-original-mark.png` — The original gradient artwork, transparent ground. Reference and large illustrative use only.
- `lynxdb-original-logo.png` — The original artwork with its wordmark. Reference only.
