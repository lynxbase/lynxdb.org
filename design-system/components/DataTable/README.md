# DataTable

Aggregated results: one row per group, columns typed.

- Headers are the `label` style on `bg-sunken`.
- Right-align numbers with the `num` class; they are mono and tabular.
- Rows are separated by `border-subtle`; there is no zebra striping and no vertical rule.
- Wrap the table in an `lx-panel` with hidden overflow to get the border and radius.
