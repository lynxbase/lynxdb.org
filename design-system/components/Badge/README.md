# Badge

One or two words of state or metadata in the `label` style.

- Neutral by default. Use a tone only when the badge reports a status, and keep the word that says so ("Healthy", "Rebuilding", "Unreachable").
- A status badge may lead with an `lx-dot`; the dot repeats the tone, it does not replace the word.
- `lx-badge--accent` marks something new or selected. Do not use it for success.
