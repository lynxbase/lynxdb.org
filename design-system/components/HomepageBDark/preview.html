Running in a minute

  • No schema to declare first.
  • No index to design or rebuild.
  • No cluster to start: a file is enough.
  1. InstallRelease binary, checksum verified, to /usr/local/bin
    $ curl -fsSL https://lynxdb.org/install.sh | sh
  2. Ask a fileNothing to start, nothing to configure
    $ lynxdb query --file access.log 'source=main status>=500 | top 10 uri'
  3. Keep the logsA server that stores them on disk
    $ lynxdb server

Try it on your own logs.
