# CodeBlock

LynxFlow and shell text on `bg-sunken`, in the `code` style.

- Wrap tokens in spans: `k` stage names, `p` the pipe, `f` functions, `s` strings and time ranges, `n` numbers, `c` comments. Fields, operators and punctuation stay `fg-default`.
- Start each stage on its own line with the pipe in column one, as the LynxDB docs do.
- Inline code is `lx-ic`.
- Follows the page theme. For shell sessions with output use Terminal.
