# Histogram

Event volume over time as plain bars.

- Ungrouped bars are `viz-neutral`. When the view is split by level, stack `viz-5` (error) and `viz-3` (warn) from the baseline and leave the rest neutral.
- Always show the time axis in mono and, when stacked, a legend with words.
- Pair it with a `lx-stat` for the total. Do not draw gridlines or a y axis for a sparkline-height chart.
