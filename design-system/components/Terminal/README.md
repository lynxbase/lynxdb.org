# Terminal

A shell session, always dark. Give the element `data-theme="dark"` whatever the page theme.

- Use it for anything a person would type at a prompt, with the output the command really prints.
- Colours come from the `ansi-*` tokens through the classes `pr`, `dim`, `b`, `a-red`, `a-green`, `a-yellow`, `a-blue`, `a-magenta`, `a-cyan`, following the CLI section's slot table.
- The title bar is optional; its three dots are grey, never red, yellow and green.
- The cursor is a static `moss-400` block. It does not blink.
